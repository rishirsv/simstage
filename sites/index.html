Install Sim Stage

Build the plugin from source and add it to Codex. Keep Xcode open with Settings → Intelligence → Model Context Protocol turned on.

  1. git clone https://github.com/rishirsv/simstage.git cd simstage
  2. bun install --frozen-lockfile bun run dev:plugin
  3. codex plugin marketplace add "$PWD/.dev-plugin" --json codex plugin add sim-stage@sim-stage-dev --json

Then start a new Codex chat and ask: “Open Sim Stage and show my simulators.”
